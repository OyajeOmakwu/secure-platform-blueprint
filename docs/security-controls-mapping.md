# Security Controls Mapping

## Example Mappings

| Control Area | Project Control | Purpose |
|---|---|---|
| Least Privilege | Non-root containers, IAM design | Reduce unnecessary privilege |
| Secure Configuration | Terraform structure, IaC review | Standardize secure defaults |
| Vulnerability Management | Trivy, dependency scanning | Identify and block risky artifacts |
| Segmentation | Kubernetes NetworkPolicy | Limit east-west traffic |
| Monitoring and Detection | Pipeline checks and reporting examples | Improve visibility into risk |
